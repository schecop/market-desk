# Market Desk — Learning Journal

Market Desk is a personal learning-by-building project: a multi-client AI research agent that answers questions about public companies over chat and voice, grounded in verified facts and SEC filings.

This site is the trace of the build: **what was built, why, and what was learned**, written during the work, not after.

| Section | What's there |

| [Journal](journal/README.md) | One section per sprint: decisions, concepts, code map, gotchas, exercises |
| [Decisions (ADRs)](adr/0001-containerise-api-in-sprint-0.md) | Lasting architectural decisions, with the alternatives considered |
| [Plan](PLAN.md) | The full project guide: architecture, stack, budget and the sprint checklists |
